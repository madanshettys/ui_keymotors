# Key Motorrs TATA - Authorized Dealership Web Application

A full-scale, enhanced clone of the official **[Key Motorrs TATA](https://keymotors.in/)** dealership website in Bengaluru, Karnataka.

Built with **React 18**, **Vite**, **Tailwind CSS**, and **Lucide Icons**, featuring all **419+ original dealership media assets** (hero banners, car models, colors, gallery handovers, brochures, and logos) hosted locally and enhanced with interactive tools.

---

## 🌟 Key Features & Enhancements

### 1. 100% Asset & Brand Fidelity
- **Official Logos & Badges**: Exact Key Motors Tata Dealership Logo and official Tata Motors branding.
- **Adaptive Hero Slider**: 10 high-resolution desktop and mobile car banners (`assets/img/slider/`) with auto-advance and pause-on-hover.
- **Complete 16-Model Tata Lineup**:
  - **Electric Vehicles**: Curvv.ev, Nexon.ev, Punch.ev, Tiago.ev, Tigor.ev, Harrier.ev, Sierra.ev
  - **SUVs & Sedans**: Curvv, Nexon, Safari, Harrier, Punch, Altroz, Tiago, Tigor, Aeris Concept
- **Real PDF Brochures**: 15 official Tata Motors product brochures (`assets/brochure/`) available for one-click download.

### 2. Powerful Interactive Enhancements
- ⚡ **Tata EV vs. Petrol Green Savings Calculator**:
  - Interactive daily Bangalore commute distance slider (10 to 180 km/day).
  - Real-time comparison between petrol running cost (~₹7.9/km) vs Tata EV electricity cost (~₹1.0/km).
  - Displays monthly net cash savings, 5-year cumulative savings, and carbon offset in equivalent trees planted.
- 💰 **Interactive Car Loan & Bangalore RTO EMI Calculator**:
  - Live sliders for Car Price, Down Payment (10%-60%), Loan Tenure (1-7 years), and Interest Rate.
  - Automatically calculates monthly EMI, Principal vs Interest ratio, and estimated Bangalore Karnataka RTO (15% for ICE vs concessional ~4% for EV).
- ⚖️ **Side-by-Side Car Comparison Tool**:
  - Compare any 2 or 3 Tata cars (e.g. Curvv vs Nexon, Harrier vs Safari) with detailed matrix (Price, Safety Rating, Range, Power, Boot Space).
- 🎨 **360° Color Customizer & Specs Explorer**:
  - Interactive exterior color changer using official Tata paint codes (Pure Grey, Virtual Sunrise, Daytona Grey, Flame Red, etc.).
  - Signature features gallery and complete technical specification tables.

### 3. Full Lead & Booking Engine
- 🚗 **Doorstep & Showroom Test Drive Booking**:
  - Choose between doorstep delivery or showroom visit.
  - Select car model, preferred Bangalore branch, date, and 2-hour time slot.
  - Generates instant unique booking reference (`KM-TD-XXXXXX`) stored in `localStorage`.
- 🔧 **Certified Service Appointment Booking**:
  - Select service type (Express 90-Min, Periodic Maintenance, AC Disinfection, Cashless Bodyshop).
  - Vehicle registration lookup and complimentary pickup/drop toggle.
- 📋 **On-Road Price Breakdown Quote**:
  - Transparent itemized quote (Ex-showroom, RTO, Insurance, Fastag, TCS).
  - One-click instant dispatch on WhatsApp.

### 4. 8 Bengaluru Showrooms & 7 Workshops
- Complete branch directory: Mysore Road (Nayandahalli Flagship), JP Nagar, Bannerghatta Road, Nelamangala, Magadi Road, Jigani, Doddaballapura, and Kanakapura Town.
- Direct click-to-call, service desk telephone, and Google Maps GPS navigation links.

## 🚀 Running the Project

```bash
# Install dependencies
npm install

# Run Vite development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
